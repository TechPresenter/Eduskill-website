# Brand Guidelines — Eduskill India Foundation

The visual identity system. Colours are implemented as **runtime CSS variables** so the owner can
re-brand from the admin without touching code.

---

## 1. Brand essence

- **Name:** Eduskill India Foundation
- **Tagline:** *Empowering underserved communities across India through education, skills, and opportunity.*
- **Personality:** trustworthy, warm, capable, transparent, hopeful.
- **Positioning:** a modern, accountable NGO that turns education & skilling into real outcomes.

## 2. Logo

- **Mark:** a rounded-square tile with the letter **“E”** in the brand gradient, `text-on-brand` colour.
- **Usage:** tile + wordmark (“Eduskill India Foundation”) in the header/footer.
- **Clear space & scale:** keep the tile ≥ 36 px; never distort; never place on low-contrast backgrounds.
- The mark uses the live brand gradient, so it re-colours automatically when the brand colour changes.

## 3. Colour palette

Colours ship as **“R G B” channel triplets** in CSS variables (`--brand-500`, etc.). A full 50→950
OKLCh lightness ramp is generated by PHP from a single chosen hex — so every shade reads as one hue.

| Token | Default hex | Use |
|---|---|---|
| **Brand** | `#4f46e5` (indigo) | Primary actions, links, accents, logo |
| **Accent** | `#10b981` (emerald) | Secondary highlights, success framing, gradients |
| **Surface** | `#ffffff` / sunken `#f8fafc` | Page & card backgrounds (dark mode re-points) |
| **Content** | `#0f172a` / muted `#475569` | Text |
| **Edge** | `#e2e8f0` | Borders & dividers |

**Semantic (fixed) status colours** — never follow the brand hue:

| Token | Hex | Meaning |
|---|---|---|
| Success | `#22c55e` | Confirmations, valid states |
| Warning | `#f59e0b` | Cautions |
| Danger | `#ef4444` | Errors, destructive actions |
| Info | `#0ea5e9` | Neutral information |

**Signature gradients:** brand→accent (`#4f46e5 → #10b981`) for CTAs; brand-700→brand-900→accent-800
for hero backgrounds.

**Accessibility:** `--on-brand` (button text on brand fill) is auto-set to black or white by measured
WCAG contrast. Maintain ≥ 4.5:1 for body text.

## 4. Typography

| Role | Typeface | Weights |
|---|---|---|
| **Display / headings** | **Plus Jakarta Sans** | 600–800 |
| **Body / UI** | **Inter** | 400–700 |
| Mono (code) | JetBrains Mono | 400–600 |

- Tight tracking on large display type (`-0.02em`); comfortable line-height for body.
- Fall back gracefully to `system-ui` if web fonts are unavailable.

## 5. UI components

- **Radius:** cards `0.875rem`, panels `1.25rem`, pills fully rounded.
- **Elevation:** soft, layered shadows (`shadow-card` → `shadow-pop` on hover).
- **Buttons:** gradient primary with sheen + ripple; glass secondary; clear focus rings.
- **Motion:** `cubic-bezier(0.16, 1, 0.3, 1)` easing; always honour `prefers-reduced-motion`.
- **Spacing:** generous section rhythm (`py-14`→`py-20`); consistent 4px spacing scale.

## 6. Imagery

- Authentic photography of learners, communities and programmes — warm, hopeful, dignified.
- Avoid stocky/staged imagery; prefer real field photos.
- 16:10 media cards; lazy-load; rounded corners consistent with card radius.

## 7. Voice & tone

- **Clear, warm, and specific.** Lead with impact and people, not jargon.
- Use concrete numbers (students reached, campaigns run) where possible.
- Be transparent about status — the admin even labels unbuilt features honestly.

## 8. Trust & compliance signals

Display registration/trust badges where relevant: **12A**, **80G tax exemption**, **CSR-1**, and
“transparent & audited”. Donation copy notes 80G eligibility.

## 9. Re-branding

Change the brand/accent colour from **Admin → Settings**. PHP regenerates the entire OKLCh ramp and
re-derives readable on-brand text automatically — no CSS rebuild required.
